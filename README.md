# Creating Automated Reports in R: An Introduction to Quarto

Have you ever spent hours formatting output from your R console into a Word document, copying and pasting chunks of code multiple times to run the same analysis on different data, or writing the world's longest code comment to keep track of your analysis pipeline? Then this workshop is for you! Quarto is a free, open source, and highly flexible technical publishing system that can be used to create reproducible, production quality reports (and more) that integrate code, output, and text. In this training, you will receive an in-depth introduction to how to use Quarto to combine text, R code, and output into reproducible reports, in addition to automating repeat analysis with Quarto parameters.

## Pre-Class Instructions

Before the class, make sure you have a recent version of R and RStudio installed: https://posit.co/download/rstudio-desktop/

Please also install the `tidyverse`, `quarto`, `knitr`, and `sclaes` packages with the R command `install.packages("tidyverse")` or using the package manager.
